# Simon Says Game

A browser-based memory game where players watch a growing sequence of colors and repeat it back by clicking. Built from scratch with plain HTML, CSS, and JavaScript - no frameworks or libraries.

**Live demo:** [file:///C:/Users/Advance%20solution/Desktop/JavaScript/Mini-Project/Simon%20says%20Game/Simon_Says_Game.html]

## About the project

I built this to get comfortable with core JavaScript concepts before moving on to frameworks - specifically DOM manipulation, event listeners, and managing state that changes over time (the growing sequence, the current level, win/loss conditions).

The game logic tracks two sequences: one generated by the computer and one entered by the player. On every click, the player's input is checked against the computer's sequence in real time, so a wrong click ends the game immediately rather than waiting until the full sequence is entered.

## How it works

- A random color is added to the sequence and flashed on screen.
- The player repeats the sequence by clicking the buttons in order.
- Each correct round increases the level and adds one more color to the sequence.
- An incorrect click ends the game, flashes the screen red, and displays the final score.
- Pressing any key restarts the game from level 1.

## Tech stack

- **HTML** - page structure and button layout
- **CSS** - styling, layout, and flash/feedback animations
- **JavaScript** - game logic, sequence generation, event handling, state management

No build tools, no dependencies. Clone it and open the HTML file - that's the whole setup.
